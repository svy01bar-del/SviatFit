# Sviat Pflege Deutsch 1.1

Навчальна програма для підготовки до Pflegefachassistenz. 18 тем, 36 підпунктів, 252 картки, 3 авторські навчальні випадки та 127 перевірюваних відповідей загалом. Український інтерфейс, денний/нічний режими, вбудоване офлайн-аудіо, 1092 записи словника, повторення за розкладом, резервні копії. Це мовна підготовка; клінічні навички відпрацьовуються з наставником.

## Нове у версії 1.1

Розділ Ausbildung 2027: дев’ять напрямів офіційної рамкової програми, правила державного іспиту й посилання на першоджерела. Факти перевірено 21.10.2026: 18 місяців очно, щонайменше 1050 годин занять і 1280 годин практики. Письмовий іспит — дві роботи по 120 хвилин; усний — 20–30 хвилин. Деталі та джерела доступні всередині програми.

Шість нових тем: роль учня, профілактика, зміни стану, реабілітація, паліативний догляд, мова завдань іспиту. Рекомендований мовний план на вісім тижнів автоматично показує прогрес уроків. Три навчальні випадки мають пояснення відповідей, поле для власного запису й озвучений зразок. Ці вправи не є офіційними білетами державного іспиту. Зовнішні офіційні сайти відкриваються через інтернет; навчальний курс працює офлайн.

## Перенесення з версії 1.0

У старій програмі відкрийте Опції → Експорт резервної копії. У новій відкрийте Опції → Імпорт резервної копії та виберіть цей JSON. Переносяться відповіді, пройдені уроки, картки, розклад повторень, нотатки, особисті переклади й імпортовані тексти.

Android 1.1 встановлюється поруч зі старою програмою під назвою Sviat Pflege 1.1. Старий тестовий ключ підпису не був збережений, тому його неможливо використати для прямого оновлення APK. Не видаляйте версію 1.0 до перевірки перенесення.

Із 10 наданих PDF витягнуто доступний текстовий шар 7 (2068 сторінок), без аналізу всіх ілюстрацій. 3 PDF без текстового шару не позначено як опрацьовані. Android підтримує імпорт PDF і розпізнавання сканів на пристрої. Лікарські алгоритми лікування не перенесено до курсу. Відомості про джерела доступні у вкладці Матеріали.

## Android

Встановіть Sviat_Pflege_Deutsch_1.1.apk. Базовий курс і весь словник слів навчальних вправ уже працюють офлайн. Для перекладу довільних додаткових слів відкрийте Налаштування та одноразово завантажте мовні моделі DE→UA (Wi-Fi за замовчуванням). Потім переклад виконується на пристрої. Аудіо курсу й словника вбудоване та працює офлайн. Для озвучення додаткових власних слів потрібен локальний німецький голос Android. PDF-скани розпізнаються локально; точність OCR залежить від якості скану.

## Windows

Розпакуйте Sviat_Pflege_Windows_1.1.zip та відкрийте Start_Pflege.cmd або index.html у сучасному Edge/Chrome. Це офлайн-програма у браузері; окремий EXE не потрібен. Перед запуском із нової папки експортуйте прогрес у старій версії й імпортуйте в новій. Інтернет для навчальних вправ не потрібен. Словник містить переклади всіх слів навчальних вправ; довільний машинний переклад і PDF-OCR доступні в Android-версії. У приватному режимі браузера або після очищення даних збереження може бути втрачено: робіть резервну копію.

## Збірка

python3 pflege/build.py --out pflege/generated
python3 -m pip install piper-tts==1.3.0
# ffmpeg must be installed for audio packaging
python3 pflege/generated/build-audio.py --root pflege/generated
cd pflege/generated/android
gradle --no-daemon assembleDebug

Джерела програми знаходяться у pflege/source; pflege/build.py збирає автономні пакети з цих файлів. Гілка pflege-learning-20261020 ізольована від основної програми SviatFit.

Збірка debug підписується тестовим Android-ключем; оновлення між окремими збірками не гарантується без сталого ключа. Перед перевстановленням експортуйте прогрес.


Вбудоване синтезоване озвучення: Piper / Thorsten Voice (CC0 dataset), https://github.com/thorstenMueller/Thorsten-Voice . Модель використовується тільки під час підготовки аудіо й не входить до програми.

Додаткові орієнтири: MAGS NRW — Pflegefachassistenz; Deutsche Alzheimer Gesellschaft — Umgang und Kommunikation (https://www.deutsche-alzheimer.de/mit-demenz-leben/umgang-und-kommunikation). Поради з комунікації адаптовані для навчальних ситуацій.
